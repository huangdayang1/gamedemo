# 🐉 龙珠格斗 Dragon Ball Fighter - 增强版

一款基于HTML5 Canvas和原生JavaScript开发的专业级龙珠主题格斗游戏，支持双人对战！

## ✨ 游戏特色

### 核心系统
- 🥋 经典龙珠角色：悟空 vs 贝吉塔（精细角色绘制）
- ⚡ 必杀技系统：龟派气功、终极闪光（华丽特效）
- 🎮 双人本地对战
- 🎯 完整的战斗机制：攻击、防御、跳跃、必杀技
- 🏆 计时和血量系统

### 高级特效
- 💥 **屏幕震动系统** - 攻击时产生震撼打击感
- ⏱️ **子弹时间/慢动作** - 暴击和必杀技触发慢动作效果
- ✨ **华丽粒子系统** - 多种粒子类型（火花、光晕、烟雾）
- 🌟 **闪白效果** - 重击时的视觉冲击
- 👻 **残影效果** - 高速移动时的动态残影
- 🔥 **气场系统** - 能量满时的视觉表现

### 战斗系统
- 💯 **连击系统** - 连续攻击计数和显示
- 💢 **暴击系统** - 15%暴击率，1.5倍伤害
- 🔢 **伤害数字显示** - 实时伤害飘字
- 🛡️ **六边形护盾** - 防御时的视觉特效
- 🎨 **动态背景** - 移动的云朵和太阳效果

## 🎮 游戏控制

### 玩家1 - 悟空 (GOKU)
- **W/A/S/D** - 上/左/下/右移动和跳跃
- **J** - 普通攻击
- **K** - 防御
- **U** - 必杀技（龟派气功）需要50%能量

### 玩家2 - 贝吉塔 (VEGETA)
- **方向键 ↑/←/↓/→** - 移动和跳跃
- **1** - 普通攻击
- **2** - 防御
- **3** - 必杀技（终极闪光）需要50%能量

## 🚀 快速开始

### 本地运行

1. 克隆或下载此项目
2. 使用任何HTTP服务器运行，例如：

```bash
# 使用Python
python -m http.server 8000

# 使用Node.js http-server
npx http-server

# 或直接用浏览器打开 index.html
```

3. 在浏览器中打开 `http://localhost:8000`
4. 点击"开始游戏"按钮开始战斗！

## 🎯 游戏机制

### 基础战斗
- 普通攻击造成10点伤害
- 暴击造成15点伤害（15%概率）
- 防御可减少75%伤害
- 攻击命中会增加能量和连击数
- 被击中会有硬直时间和击退效果

### 必杀技
- 消耗50点能量
- 造成25点伤害（暴击37.5）
- 无法防御
- 带有华丽的能量波特效
- 触发屏幕震动和慢动作

### 视觉反馈
- **普通攻击**: 轻微震动 + 火花粒子
- **暴击**: 中等震动 + 慢动作 + 闪白效果
- **必杀技**: 强烈震动 + 慢动作 + 爆炸特效

### 胜利条件
- 击败对手（血量归零）
- 时间结束时血量更高的一方获胜
- 每局限时99秒
