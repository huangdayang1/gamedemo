# 🐉 龙珠格斗 Dragon Ball Fighter

一款基于HTML5 Canvas和原生JavaScript开发的龙珠主题格斗游戏，支持双人对战！

## ✨ 游戏特色

- 🥋 经典龙珠角色：悟空 vs 贝吉塔
- ⚡ 必杀技系统：龟派气功、终极闪光
- 💫 华丽的粒子特效系统
- 🎮 双人本地对战
- 🎯 完整的战斗机制：攻击、防御、跳跃、必杀技
- 🏆 计时和血量系统

## 🎮 游戏控制

### 玩家1 - 悟空 (GOKU)
- **W/A/S/D** - 上/左/下/右移动和跳跃
- **J** - 普通攻击
- **K** - 防御
- **U** - 必杀技（龟派气功）需要50%能量

### 玩家2 - 贝吉塔 (VEGETA)
- **方向键 ↑/←/↓/→** - 移动和跳跃
- **1** - 普通攻击
- **2** - 防御
- **3** - 必杀技（终极闪光）需要50%能量

## 🚀 快速开始

### 本地运行

1. 克隆或下载此项目
2. 使用任何HTTP服务器运行，例如：

```bash
# 使用Python
python -m http.server 8000

# 使用Node.js http-server
npx http-server

# 或直接用浏览器打开 index.html
```

3. 在浏览器中打开 `http://localhost:8000`
4. 点击"开始游戏"按钮开始战斗！

## 🎯 游戏机制

### 基础战斗
- 普通攻击造成8点伤害
- 防御可减少70%伤害
- 攻击命中会增加能量
- 被击中会有硬直时间

### 必杀技
- 消耗50点能量
- 造成20点伤害
- 无法防御
- 带有华丽的能量波特效

### 胜利条件
- 击败对手（血量归零）
- 时间结束时血量更高的一方获胜
- 每局限时99秒
